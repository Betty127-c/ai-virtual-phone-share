寄云功能汇总
10.21 二次更新：新增智能记忆，角色人设动态演变。防止记忆缓存太多导致模型变笨，防止人设固化，告别没有动态演变的过程！
🛠️ 四大建卡体系全面成型
• 单人卡：P1-P3 字段优先级划分，防套取人设，完美把控角色底线。
• 多人卡：支持多角色同场，设定出场顺序。开启“导演模式”，AI 主动推动群像剧情。
• 模拟器卡：内置状态机。自定义数值面板、回合流程，AI 通过 <SET> 标签自动结算数值。
• 延伸卡：粘贴原作设定，设定“if 线”分歧点，自动继承原作推演新世界线。
💬 沉浸式聊天与超强记忆
• 小说级排版：区分对话、心理、旁白，支持 HTML/CSS 及代码块直接渲染。
• 智能记忆与动态演变：全新机制打破“人设固化”，角色心智随剧情动态演变。智能管理记忆缓存，防止长对话导致模型变笨。
• 全新记忆区：满 10 条自动归档长期，支持手动增删、压缩永久记忆，配有绝美明信片 UI。
• 物品栏交互：支持设置解锁条件与交互动作，聊天中点击箱子即可使用并改变剧情。
• 动态侧边栏：支持自定义 HTML 注入，可用 {{地点}}、{{好感度}} 等变量打造实时状态面板。
• 云云助手：官方新手向导，一键复制美化模板、解答疑难杂症。
🎨 极致的美化与 UI 升级
• 应用美化中心：内置 10 套高级全局主题，支持自定义 CSS 并保存预设。
• 消息页焕新：自动分离“收藏”与“全部”，丝滑左滑删除，卡片式排版更清爽。
• 悬浮套件：聊天页新增快捷悬浮球、一键回顶/回底、本地音乐播放器。
• 显示调节：支持聊天背景亮度、模糊度、蒙版透明度实时调节。
⚙️ 模型管理与数据安全
• 多 API 管理：主 API 管正文，副 API 管记忆，支持主 API 失败时自动切换。
• 底层调用日志：实时记录每次模型调用的用途与结果。
• 作者主页 2.0：沉浸式背景、富文本签名、防重名唯一身份码。
• 一键备份：支持打包导出/导入全部数据，API Key 自动擦除。
• 高危：彻底清空数据：在我的-数据备份处，经过双重警告确认后，将同步销毁云端卡片并清空本机所有记录。
🔧 性能优化与修复
• 优化流式输出节流机制，解决长对话卡顿。
• 修复消息列表头像遮挡、左滑删除错位等 UI 问题。
• 优化导入功能，智能识别 DOCX/TXT/MD/PNG/JSON 格式。
• 修复聊天页音乐播放器链接保存失败的问题。
💡 作者说明
寄云会进行不定时的更新与功能优化，以持续为您提供更好的体验。为保障您的数据安全，建议在清理浏览器缓存或更换设备前，前往「我的 - 数据备份」进行全量导出。

10.19更新
本次更新内容：


1. 新增悬浮球功能（聊天页 / 菜单页 / 记忆页）


基础交互：单击展开快捷菜单，双击返回上一级，支持全屏拖拽并自动吸附边缘。
自定义功能：长按悬浮球可配置最多 4 个快捷功能菜单。
外观自定义：在右上角设置中，支持上传本地图片、输入图片链接或自定义 CSS 来替换悬浮球外观。
2. 记忆区页面修改


调整了记忆区页面的内容排版与展示样式。
3. 大部分 UI 与交互重构


弹窗重排：背景显示、悬浮球外观等设置面板采用分段 Tab 页，去除冗余空间，解决页面突兀问题。
深色适配：修复了输入框上方按钮、发送按钮、物品栏等图标在深色背景下看不清的问题，统一调整了图标颜色。
4. 上下文与设置更新


更新了模型上下文窗口大小及单次最大 Token 输出的底层配置。
优化了正文与记忆总结的注入逻辑。
