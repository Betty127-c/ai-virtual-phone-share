自习室 · 应用介绍
 
简介
番茄钟 + AI 任务拆解 + Anki 词书背诵 + 角色陪读。可换背景图与角色立绘，专注时界面自动淡出。
 
详细介绍
 
一个让「坐下来开始学」变简单的自习工具
 
番茄钟管节奏，艾宾浩斯管记忆，角色陪读管情绪，AI 拆解管启动难度。
 
◷ 专注
环形表盘计时，专注 → 短休 → 长休自动流转。计时用锚点时间戳，锁屏、切后台、关掉再回来都不飘，期间走完的番茄会自动补记。支持跳过阶段、+5 分钟、绑定任务、自定义各阶段时长。内置雨声，也可填自己的音频直链。
 
进入专注后界面会自动淡出——按钮、底栏、聊天窗口逐渐隐去，轻点屏幕唤回，让视野只剩计时器和背景。番茄结束只在应用内轻提示，不弹系统通知、不产生任何红点。
 
☰ 待办 · AI 拆解
把任务描述给 AI（总量、期限、自己的难点），它会拆成 3–8 步能立刻动手的小步骤：第一条足够小、总量大的按数量分块、禁止「准备一下」这类空话。拆出的步骤逐条可勾选，确认后加入子任务。治拖延，降启动难度。
 
◆ 背诵
直接导入 Anki 的 .apkg 词书（也支持 csv / txt），词书里的图片和发音音频一并带进来。SM-2 自适应调度：两档评分「会 / 不会」，「不会」当天会再出现一次；到期没做只累积、不惩罚，允许拖延。内置 LaTeX 渲染，公式书也能正常显示。复习时可让 AI 生成助记。
 
◍ 陪读
上传材料（txt / md / csv / 代码 / 图片 / PDF）和你的角色一起学，可让它讲解重点；角色还可以在专注开始、番茄完成、复习结束时说两句——有硬限频，同一个番茄最多 2 次、间隔 8 分钟，不会变成骚扰。
 
▦ 统计
连续 / 最长 / 累计打卡天数、近 12 周热力图（点格子看当天明细）、当月日历、累计番茄与专注分钟。
 
⚙ 外观
两套低饱和配色（暖米纸 / 冷灰蓝）、浅色深色跟随系统、自定义 CSS 换肤；背景图可上传任意图片，也可以直接选角色立绘——之后你在角色里换了图，这里会自动跟着变。配了背景图后按钮、卡片、聊天气泡自动转毛玻璃质感，不再挡脸。
 
使用提示
 
首次使用请先到 设置 → API 设置 配置 LLM API（角色陪读与 AI 拆解需要）
陪读角色在右上角选择；再于 设置 里选择调用链路：角色链路（带人设与记忆，更像本人）或通用链路（省 token）
「学习记录写入角色记忆」开启后，你在自习室做的事会被角色知道——聊天时 TA 会说「你今天背了好多单词」
背诵页支持一键导出 / 导入备份，建议每周导一次
