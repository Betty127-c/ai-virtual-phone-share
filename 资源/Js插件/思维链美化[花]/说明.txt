[蓝]功能简介：[/蓝]
[粉]（效果如图）[/粉]将原生全屏弹窗式的“思考过程”，转换为在聊天列表内直接展开的折叠面板，并移除了原生翻译功能。
1. 内联展开：隐藏原生触发按钮，将思维链内容固定显示在头像上方。点击标题可展开/收起，带有箭头旋转动画。
2. 防误触：移除原生自带的翻译按钮，避免误触调用 API 产生费用。
3. 样式重置：去除了原生弹窗背景，采用透明背景，内容区左侧增加竖线引导。
4. [粉]自定义设置（支持实时生效）[/粉]：
· 标题文字（支持自定义字符，如：✞𝕿𝖍𝖎𝖓𝖐𝖎𝖓𝖌✞）
· 标题颜色 / 字号
· 左侧竖线颜色
· 思考内容颜色 / 字号


[蓝]注意事项：[/蓝]
1. 源码依赖：本插件基于原作者的开源源码结构制作。
2. 兼容性：如果你使用的是未经修改的原版部署，可以正常使用；[红]如果使用的是他人二次修改过底层结构的源码，可能会导致插件失效[/红]。
3. 安全说明：插件仅做前端 DOM 渲染，不修改任何仓库底层源码。[红]随时停用或卸载，原生功能即可恢复[/红]。
