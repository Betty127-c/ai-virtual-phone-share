简介：
为 Float 原生朋友圈增加多图发布能力。用户朋友圈最多可选择 9 张图片，编辑页使用三列预览，发布后按朋友圈九宫格显示；当 API 配置开启图片识别时，Moments 的 AI 评论 / 回复 / reaction 等请求会收到当前朋友圈的全部图片，而不是只收到第一张。

功能：
- 最多 9 张图片
- 支持一次多选并继续追加
- 发布前可单张删除
- 编辑页三列统一尺寸预览
- 已发布朋友圈九宫格
- 点击图片查看大图
- 全部图片进入支持视觉的 Moments 模型请求
- 不修改 Float 核心源码
- 兼容原有单图朋友圈
- 禁用插件后原生朋友圈仍可使用

兼容性：
已验证当前原版 Float main / Chat Plugin API v1（2026-10-07）。
本插件除了使用公开 Plugin API，也会读取当前 Float 的朋友圈 DOM 与本地 IndexedDB，因此未来 Float 如果重构朋友圈页面或数据库结构，插件可能需要更新。

重要数据提示：
第一张图片继续使用 Float 原生朋友圈数据；第 2–9 张图片保存在 Float 现有图片资产库，对应关系保存在插件私有存储。
可以“禁用”插件，但不要直接“卸载”仍在使用的插件。卸载会删除插件私有绑定，已经发布的多图朋友圈会退回原生单图显示，只剩第一张能够按原生方式关联显示。

使用要求：
需要 Float 支持 Chat Plugin API v1。
若希望模型理解多张图片，所使用的 API / 模型需要支持视觉，并在 Float API 设置中开启图片识别。
